# Inter fonts

`Inter-Regular.ttf` and `Inter-SemiBold.ttf` are the unchanged static fonts from
`extras/ttf` in the official [Inter 4.1 release archive](https://github.com/rsms/inter/releases/download/v4.1/Inter-4.1.zip).

`LICENSE.txt` is Inter's license. Keep it with the fonts and ship it in every
native package.
